Read the story and the code it touches, then write `.workflowleaf/plan.md`.
Do not change any other file in this stage.

The plan has these sections, in this order:

- `## Change`: what changes, file by file, and why each file is on the list.
- `## Tests`: the test that proves each behaviour change. Name the file and
  say what the test asserts. A change with no test says why it cannot have one.
- `## Done when`: one line a person could check without reading the diff.
- `## Out of scope`: what this story does not do, so review can hold it to that.

Keep it short. The build stage reads it instead of this conversation.
